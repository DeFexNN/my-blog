## XORD CTF Writeup

This challenge is a classic example of a **Known Plaintext Attack** or **Predictable RNG (Random Number Generator)** vulnerability. The script uses bitwise XOR to encrypt a flag, but it does so using a pseudo-random sequence that is entirely deterministic.

### 1. Analysis of `xord.py`

The encryption script performs the following steps:

1. 
**Seed Initialization**: It sets a static seed for the Python `random` module using `random.seed(1337)`.


2. 
**Encryption Loop**: For every character in the flag, it generates a "random" integer between 0 and 255.


3. 
**XOR Operation**: It XORs the ASCII value of the character with the generated random key.


4. 
**Output**: The resulting bytes are converted to a hex string and saved in `output.txt`.



### 2. The Vulnerability

The flaw lies in the **fixed seed**. In computer science, "random" numbers are usually pseudo-random, meaning they are generated by an algorithm starting from a "seed" value.

* If the seed is the same, the sequence of numbers generated will be **identical** every time the script is run.


* Because we have the seed (`1337`) and the algorithm (Python's `random.randint`), we can perfectly recreate the key used for every byte of the flag.



### 3. Exploitation Logic

The XOR operation () has a unique property: if you XOR the result () with the key () again, you get the original value () back.

To solve this, we simply need to:

1. Read the hex string from `output.txt` and convert it back to bytes.


2. Initialize the Python `random` module with `seed(1337)`.


3. Iterate through the encrypted bytes, generating a key for each one, and XOR them to reveal the original characters.



### 4. Solution Script

```python
import random

# The hex content provided in output.txt
encrypted_hex = "cb35d9a7d9f18b3cfc4ce8b852edfaa2e83dcd4fb44a35909ff3395a2656e1756f3b505bf53b949335ceec1b70e0"
encrypted_bytes = bytes.fromhex(encrypted_hex)

# Synchronize the RNG with the same seed used in xord.py
random.seed(1337)

flag = ""
for b in encrypted_bytes:
    # Generate the exact same key sequence
    key = random.randint(0, 255)
    # Reverse the XOR
    flag += chr(b ^ key)

print(f"Decrypted Flag: {flag}")

```

### 5. Final Result

Running the script reveals the flag:
**`pascalCTF{x0r_15_n0t_th4t_h4rd_w1th_4_f1x3d_533d}`**
